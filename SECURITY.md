# SECURITY

## Границы доверия

- GitHub Pages и весь JavaScript считаются публичными.
- Любые значения, помещённые во frontend, доступны посетителю сайта.
- NocoDB является внешним источником контента.
- `localStorage` содержит только личные заметки и игровой прогресс.

## Текущий критичный риск

Read-token NocoDB встроен в `script.js`. Его нельзя считать секретом. В stabilization RC он временно сохранён ради совместимости: удаление без готового Worker/API остановит загрузку меню.

## Обязательный следующий этап

1. Создать Worker/API только для разрешённых read-запросов.
2. Хранить NocoDB token только в server-side secret.
3. Ограничить поля, таблицы, лимиты и методы.
4. Добавить тайм-аут, rate limit и безопасный CORS.
5. Переключить frontend на Worker/API.
6. Ротировать текущий публичный токен.

До выполнения этого этапа через текущий токен нельзя разрешать запись, административные операции или доступ к чувствительным данным.
