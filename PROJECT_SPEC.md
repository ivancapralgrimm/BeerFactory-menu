# PROJECT SPEC

## Назначение

Mobile-first справочник BeerFactory: меню и ТТК, обучение персонала, аттестация и дополнительная игра. Текущий этап — временный статический портал на GitHub Pages.

## Source of truth

| Данные | Источник истины | Поведение при ошибке |
|---|---|---|
| Меню и ТТК | NocoDB: основная и кухонная таблицы | Мгновенно показываются встроенные резервные карточки |
| Статьи | `training-data.txt` | Показываются встроенные демо-статьи |
| Вопросы | `questions.txt` | Старт аттестации блокируется с понятной ошибкой |
| Личные заметки | `localStorage` конкретного устройства | Статья работает, даже если хранилище недоступно |
| Судоку | `localStorage` конкретного устройства | Игра работает без сохранения прогресса |

`localStorage` не является backend и не используется для рабочих или административных данных.

## Runtime

- Статические HTML/CSS/JS без сборщика.
- Публикация через GitHub Pages.
- Меню загружается напрямую из NocoDB из браузера.
- Внешний вид и текущие пользовательские сценарии сохраняются до отдельного продуктового этапа.

## Стабилизация RC

- резервные карточки выводятся до ответа NocoDB;
- у каждого запроса есть тайм-аут;
- частичный отказ одной таблицы не обрушает вторую;
- устранены конкурирующие отложенные перерисовки;
- поиск охватывает название, категорию, теги, состав, метод и подачу;
- нормализованы категории и неполные значения NocoDB;
- пустая категория больше не ломает случайный выбор;
- динамическая высота карточки пересчитывается после фото и калькулятора;
- данные, вставляемые в HTML, экранируются;
- заметки и сохранение судоку не ломают страницу при запрете `localStorage`;
- повреждённое сохранение судоку валидируется и игнорируется;
- таймер судоку приостанавливается в фоне;
- добавлены safe-area и видимый keyboard focus.

## Известное ограничение

NocoDB read-token сейчас находится во frontend. Это наследуемая схема текущей версии, а не безопасная production-архитектура. Перенос чтения через Worker/API и ротация токена запланированы отдельно: удаление токена сейчас без готового proxy сломает меню.
